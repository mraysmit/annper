# Generated Legacy Baseline Evidence

Files in this directory are generated by
`../tools/Build-ControlledArtifacts.ps1` from the configured read-only legacy
source roots. Do not hand-edit generated CSV or checksum files.

- `legacy-file-inventory.csv`: file-level inventory and hashes.
- `legacy-source.sha256`: portable SHA-256 checksum list.
- `legacy-source-manifest.sha256`: identity of the checksum list.
