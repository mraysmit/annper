## 7. Gotchas

- **Line endings.** `baseline/legacy-source.sha256` is hashed byte for byte, and its recorded identity is of the file with CRLF line endings. `.gitattributes` marks the baseline files `-text` so git never converts them; keep that rule, or checkouts on Linux, macOS or with `core.autocrlf=false` fail the manifest check.
- **Mockup indentation.** The tests find prototype functions by their four-space indentation; running a code formatter over the prototypes breaks them.
- **Gate text drives the matrix.** NFR and FR-ACC phases are read from the gate text in governance plan §5, so editing a gate changes the matrix; regenerate afterwards.
- **No new files in `docs/`.** The validator rejects any file there that is not in its allowed list.
- **Share paths.** Only governance plan §9.1 may hold the reviewed network location.
- **Commit messages.** Commits `4924685` and `4db0ad5` say "Refactor code structure" but changed documents; describe document changes as such.
